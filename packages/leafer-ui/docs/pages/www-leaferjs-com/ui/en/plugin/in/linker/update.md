# Linker Changelog 

View Documentation

## 2026 / 08 / 03 

> v1.0.2

#### 🌱 Added 

* 🌸 Added the points property for adding waypoint coordinates.
* 🌸 Added the curve property for controlling curve curvature or customizing the smoothing method.

## 2026 / 07 / 14 

> v1.0.1

#### 🪲 Fixed 

* 🌸 Fixed an issue where connection elements could occasionally fail to render when dragging elements in the auto-connected direction after the connection element was nested within multiple layers.

@black

## 2026 / 06 / 02 

> v1.0.0

#### 🌱 Added 

* 🌸 After being validated in users' production environments with no significant issues, Linker is now officially released.

## 2026 / 03 / 30 

> v1.0.0-beta.4

#### 🌱 Added 

* 🌸 Added support for creating connection elements by dragging.
* 🌸 Added support for connection elements with flow animations.
* 🌸 Added support for multiple modes when automatically creating connection points, allowing connections to snap to 4 directions, 8 directions, or any point.

#### 🪲 Fixed 

* 🌸 Fixed an issue where automatically created connection points had incorrect directions when created through methods.

@CML

## 2026 / 03 / 11 

> v1.0.0-beta.3

#### 🪲 Fixed 

* 🌸 Fixed an issue where connection lines were not updated when moving a group after elements had been grouped.

@black
