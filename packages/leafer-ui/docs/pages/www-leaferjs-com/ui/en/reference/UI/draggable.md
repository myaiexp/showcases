# draggable 

Drag functionality.

## Key Properties 

### draggable: ``` boolean ``` | ``` 'x' ``` | ``` 'y' ``` 

Whether dragging is enabled. You can restrict movement to the x-axis or y-axis. Default is

```
false
```

.

Also supports drag bounds restriction.
