marked.js.org →

A fast, low-level Markdown compiler that turns Markdown into HTML in the browser or on the server — the engine behind countless live editors and docs sites.

Parsing
Why it's interesting: Marked parses GitHub-Flavored Markdown — tables, task lists, strikethrough, fenced code — in a single fast pass, with no dependencies. It's the quickest way to add a live preview or render user content. But Marked deliberately does not sanitize its output: any raw HTML in the source passes straight through. That's why it pairs naturally with DOMPurify — Marked turns Markdown into HTML, DOMPurify makes that HTML safe to insert into the page.

// Marked (UMD global) + DOMPurify (UMD global)
function render(markdown) {
  const rawHtml = marked.parse(markdown);     // Markdown → HTML string
  const safeHtml = DOMPurify.sanitize(rawHtml); // strip anything dangerous
  preview.innerHTML = safeHtml;
}

input.addEventListener("input", () => render(input.value));
