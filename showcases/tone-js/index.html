Tone.js

tonejs.github.io →

A Web Audio framework for making music in the browser. Synthesizers, effects, and a musical transport for scheduling — sound generated entirely in code, no audio files.

Audio
Why it's interesting: The raw Web Audio API is powerful but low-level — you wire oscillators, gain nodes, and sample-accurate timing by hand. Tone.js wraps it in musical concepts: synths you can play with note names like "C4", a Transport that schedules events on a musical timeline (bars, beats, BPM), and a library of effects. Everything here is synthesized live in your browser, so there's nothing to download. It's the fastest way to add real, interactive sound to a web app.
🔊 Audio needs a tap to start (browsers block autoplay). Turn your volume up and click a note.

Playable Synth

Each button triggers a note on a Tone.Synth. Change the oscillator waveform to hear how the timbre shifts — a sine is pure and round, a sawtooth is bright and buzzy.

View Code 
const synth = new Tone.Synth({
  oscillator: { type: "triangle" }
}).toDestination();

button.addEventListener("click", async () => {
  await Tone.start();            // resume the AudioContext (needs a gesture)
  synth.triggerAttackRelease("C4", "8n");  // note, duration
});

Step Sequencer

Toggle steps to program a loop, then press play. A Tone.Sequence walks the steps in time with the Transport, firing a note on each active one. Drag the tempo to feel the BPM change.

View Code 
const synth = new Tone.PolySynth(Tone.Synth).toDestination();
const notes = ["C4","D4","E4","G4","A4","C5","D5","E5"];
const active = new Array(8).fill(false);

const seq = new Tone.Sequence((time, step) => {
  if (active[step]) synth.triggerAttackRelease(notes[step], "8n", time);
  // schedule the UI highlight on the animation frame
  Tone.getDraw().schedule(() => highlight(step), time);
}, [0,1,2,3,4,5,6,7], "8n").start(0);

playBtn.onclick = async () => {
  await Tone.start();
  Tone.getTransport().toggle();   // start / stop
};
