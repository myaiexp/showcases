Zdog

zzz.dog →

A round, flat, designer-friendly pseudo-3D engine. Build true 3D models from simple shapes and render them with a clean, illustrative look on a single canvas.

Visual
Why it's interesting: Zdog is "3D for designers." It's only ~2,000 lines, yet it gives you a real 3D scene graph — shapes have genuine positions, rotations, and depth sorting — rendered in a soft, flat, vector style instead of photoreal lighting. You compose models from primitives (boxes, cones, ellipses), spin them with a render loop, and let users drag to orbit. It's the easiest on-ramp to 3D on the web when you want charm over realism.

Spin & Drag

A 3D box with six colored faces, auto-rotating in a render loop. Drag it to orbit — dragRotate handles the pointer math, including touch. Toggle the spin to inspect it from any angle.

const illo = new Zdog.Illustration({
  element: canvas,
  dragRotate: true,        // drag / touch to orbit
  zoom: 4
});

new Zdog.Box({
  addTo: illo,
  width: 90, height: 90, depth: 90,
  stroke: false,
  frontFace: "#e5484d", rearFace: "#6c8cff",
  leftFace: "#8c6cff",  rightFace: "#19b8c4",
  topFace: "#30a46c",   bottomFace: "#f5a623"
});

function animate() {
  if (spinning) illo.rotate.y += 0.03;
  illo.updateRenderGraph();   // recompute depth order + draw
  requestAnimationFrame(animate);
}

Primitive Explorer

Zdog ships a handful of 3D primitives. Pick one and tune the zoom and spin speed — the shape is rebuilt with a single constructor call and the loop keeps it turning.

function build(type) {
  current?.remove();                 // drop the previous primitive
  const opts = { addTo: illo, color: "#6c8cff", stroke: 12 };
  current = ({
    box:        () => new Zdog.Box({ ...opts, width: 80, height: 80, depth: 80, stroke: false, color: "#8c6cff" }),
    sphere:     () => new Zdog.Shape({ ...opts, stroke: 90 }),
    cone:       () => new Zdog.Cone({ ...opts, diameter: 80, length: 90 }),
    cylinder:   () => new Zdog.Cylinder({ ...opts, diameter: 70, length: 80 }),
    hemisphere: () => new Zdog.Hemisphere({ ...opts, diameter: 90 })
  })[type]();
}
