Sortable.js

sortablejs.github.io →

Reorderable drag-and-drop lists with smooth animations and touch support — no framework required, just a plain DOM element.

Interaction
Why it's interesting: Drag-and-drop reordering is deceptively hard to build well: pointer math, touch events, auto-scroll, and animations all fight you. Sortable.js wraps the native HTML5 drag-and-drop API into one tiny, dependency-free library. Point it at a list element and items become reorderable instantly — with FLIP animations, drag handles, and transfer between lists. It's the quiet workhorse behind countless Kanban boards and playlist editors.

Reorderable List

Drag the rows by their handle to reorder this priority list. Sortable animates the shift and fires onSort — the readout below reflects the live order. Works with touch, too.

import Sortable from "sortablejs";

const sortable = new Sortable(listEl, {
  animation: 150,           // FLIP animation duration (ms)
  handle: ".handle",        // only the handle starts a drag
  ghostClass: "sortable-ghost",
  chosenClass: "sortable-chosen",
  onSort: () => {
    // Read the new order straight off the DOM
    const order = sortable.toArray();
    console.log(order);
  }
});
