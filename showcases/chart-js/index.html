Chart.js

chartjs.org →

Simple, flexible charting on an HTML canvas. Eight chart types, animated transitions, and sensible defaults — a few lines of config and you have a responsive graph.

Data/Viz
Why it's interesting: Chart.js hits the sweet spot between "too basic" and "you need a PhD in D3." It renders to a single <canvas>, so charts stay fast even with lots of points, and every update animates automatically. You describe the chart declaratively — type, data, options — and mutating the data then calling chart.update() tweens smoothly to the new values. It's the default reach-for when you want good-looking charts without fighting a visualization grammar.

Live, Editable Data

Drag the sliders to change the monthly figures. Each change mutates the dataset and calls chart.update() — Chart.js tweens the bars to their new heights.

View Code 
const chart = new Chart(ctx, {
  type: "bar",
  data: {
    labels: ["Jan", "Feb", "Mar", "Apr", "May", "Jun"],
    datasets: [{ label: "Revenue ($k)", data: values }]
  },
  options: { responsive: true, maintainAspectRatio: false }
});

// Mutate the data, then update — Chart.js animates the change
slider.addEventListener("input", () => {
  chart.data.datasets[0].data[month] = Number(slider.value);
  chart.update();
});

One Dataset, Many Chart Types

The same numbers tell a different story depending on the chart. Switch types to see how Chart.js re-renders — bars and lines use X/Y axes, while doughnut, polar, and radar are radial.

View Code 
let chart;
function build(type) {
  chart?.destroy();          // tear down the old one
  chart = new Chart(ctx, {
    type,                    // "bar" | "line" | "radar" | "doughnut" | "polarArea"
    data: { labels, datasets: [{ label: "Traffic", data }] },
    options: { responsive: true, maintainAspectRatio: false }
  });
}

button.addEventListener("click", () => build(button.dataset.type));
