Pizzicato.js

alemangui.github.io/pizzicato →

A friendly wrapper over the Web Audio API. Create sounds from oscillators or files and chain effects with a clean, approachable interface.

Audio
Why it's interesting: Pizzicato simplifies the Web Audio API down to two ideas: sounds and effects. A sound can come from an oscillator wave, a file, or the microphone; effects like delay, distortion, and tremolo are objects you add and remove from the chain on the fly. Compared to a full framework it's tiny and unopinionated — perfect when you just want to generate a tone or add a quick audio effect without learning the whole Web Audio graph.
🔊 Audio needs a tap to start (browsers block autoplay). Turn your volume up and press play.

Tone Generator

A single oscillator you can shape live. Pick a waveform and sweep the frequency — Pizzicato updates the running sound in place, no restart needed.

View Code 
const sound = new Pizzicato.Sound({
  source: "wave",
  options: { type: "sawtooth", frequency: 220 }
});

playBtn.onclick = () => {
  Pizzicato.context.resume();   // unlock audio on the gesture
  sound.playing ? sound.stop() : sound.play();
};

freq.oninput = () => { sound.frequency = Number(freq.value); }; // live
vol.oninput  = () => { sound.volume = Number(vol.value); };

Effects Rack

A steady drone with four effects you can patch in and out while it plays. Each effect is an object — addEffect() inserts it into the chain, removeEffect() pulls it back out.

const drone = new Pizzicato.Sound({
  source: "wave", options: { type: "sawtooth", frequency: 110 }
});

const delay = new Pizzicato.Effects.Delay({ feedback: 0.6, time: 0.3, mix: 0.5 });

checkbox.onchange = () => {
  checkbox.checked ? drone.addEffect(delay) : drone.removeEffect(delay);
};
slider.oninput = () => { delay.feedback = Number(slider.value); }; // tweak live
