The industry-standard JavaScript animation engine. Timelines, easing, and silky-smooth tweens that run anywhere — DOM, SVG, canvas, WebGL.

Animation
Why it's interesting: GSAP (GreenSock Animation Platform) is the tool the web's most impressive sites reach for. Unlike CSS transitions, it gives you precise, scriptable control: sequence dozens of animations on a timeline, scrub them back and forth, and choose from a deep library of eases that make motion feel physical. It's framework-agnostic, battle-tested for over a decade, and as of v3.12 the full toolkit (including former Club plugins) is free.

Timeline & Stagger

A timeline sequences many tweens with a single playhead. Use the controls to play, pause, and reverse — or drag the scrubber to move the playhead by hand. Notice how stagger offsets each bar automatically.

// Build a timeline once, then drive it with controls
const tl = gsap.timeline({ paused: true });

tl.from(".bar", {
  scaleY: 0,        // grow up from the baseline
  opacity: 0,
  rotation: -8,
  duration: 0.6,
  ease: "back.out(1.7)",
  stagger: 0.12     // offset each element by 0.12s
})
.to(".bar", {
  scaleY: 0.4,
  duration: 0.4,
  ease: "power2.inOut",
  stagger: { each: 0.08, yoyo: true, repeat: 1 }
});

play.onclick    = () => tl.play();
pause.onclick   = () => tl.pause();
reverse.onclick = () => tl.reverse();
restart.onclick = () => tl.restart();

// Two-way scrubbing: timeline ↔ slider
scrub.oninput   = () => tl.progress(scrub.value / 1000);
tl.eventCallback("onUpdate", () => {
  scrub.value = tl.progress() * 1000;
});
