Tippy.js

atomiks.github.io/tippyjs →

The complete tooltip, popover, and dropdown solution. Positioned by Popper, so it flips and shifts to stay on-screen — no manual coordinate math.

Layout/UI
Why it's interesting: Positioning a floating element that never clips off-screen is a genuinely hard problem. Tippy.js sits on top of Popper and solves it: tooltips automatically flip to the opposite side when there's no room and shift to stay in the viewport. Beyond plain tooltips it does interactive popovers, click-triggered dropdowns, custom HTML, themes, and animations — all from a single function call. It's the fastest path from "I need a tooltip" to something that feels polished.

Tooltips & Smart Placement

Hover the button to see its tooltip. Change the placement and trigger below and the tooltip updates live via setProps(). Popper keeps it on-screen even near the edges.

View Code 
// Tippy.js needs Popper loaded first (window.Popper)
const instance = tippy("#tipTarget", {
  content: "I flip and shift to stay on screen ✨",
  placement: "top",       // top | bottom | left | right | auto
  trigger: "mouseenter focus",
  arrow: true,
  animation: "shift-away"
})[0];

// Update options at runtime — no re-creation needed
select.addEventListener("change", () => {
  instance.setProps({ placement: select.value });
});

Interactive HTML Popover

With interactive: true and allowHTML, a Tippy becomes a click-triggered dropdown you can move your mouse into. Here's a little account menu built entirely from a tooltip.

tippy("#menuBtn", {
  content: document.getElementById("menuTemplate").innerHTML,
  allowHTML: true,        // render the markup, don't escape it
  interactive: true,      // let the mouse enter the popover
  trigger: "click",       // open on click, close on outside click
  placement: "bottom-end",
  theme: "accent",
  appendTo: () => document.body
});
